# MB Player (Android 7+)

Native app for the Vordon stereo. Plays files from mb.rakendus.biz with the DSP inside the app
(EQ 16 bands, subsonic HP, LP, sub, bass harmonics, width, compressor, saturation, limiter,
loudness matching), reads the same settings the web player saves on the server.

Build: push to GitHub -> Actions -> "Build APK" -> artifact "mb-apk" (contains mb.apk).
